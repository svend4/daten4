# Dynamic Planner

Динамический планировщик с шаблонами для мероприятий, проектов, контента и личных целей. В корне находятся отдельные HTML-демонстрации, а полнофункциональная версия размещена в `ai-planner/` и, согласно описанию проекта, предусматривает подключение ИИ.

См. `ai-planner/README.md`.
